**Segments to record:**

## SCREEN RECORDING PREP

Before recording screen sessions, prepare:

1. **Clean browser** — new Chrome profile, no personal bookmarks, no distracting extensions
2. **Example property** — use YOUR property or create a demo account on each platform
3. **Zoom level** — set browser to 125-150% zoom so text is readable on mobile
4. **Notifications OFF** — disable all system and browser notifications
5. **Cursor highlighting** — install a cursor highlighter extension so viewers can follow your clicks
6. **Script near screen** — have the lesson script on a second monitor or printed beside you

## QUALITY NOTES SPECIFIC TO MODULE 1

- Screen recordings must show REAL platform interfaces — this builds trust that you know the tools
- If you're not yet on a platform, create an account and walk through setup BEFORE recording
- Blur any personal information (email, phone, address) in screen recordings
- Show both desktop and briefly mention mobile for each platform (many hosts manage on phone)
- The Rankbreeze walkthrough is a soft affiliate sell — mention the price ($29/mo) and why it's worth it, but don't be pushy
