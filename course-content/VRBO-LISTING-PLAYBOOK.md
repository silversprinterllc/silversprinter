# VRBO Listing Setup Playbook

> The complete step-by-step guide to adding a property to VRBO, optimized for lakefront and premium STR properties. Includes ready-to-use copy for Lakeside Landing FLX and Smooth Sailing.

**Module:** Module 1, Lesson 1.3 — VRBO & Booking.com
**Estimated Time:** 90-120 minutes per property
**Outcome:** Live, optimized VRBO listing accepting bookings

---

## WHY VRBO MATTERS (60-SECOND JUSTIFICATION)

| Metric | Why It Matters |
|---|---|
| 20-30% booking lift for lakefront properties | VRBO's core audience is families and groups booking whole-home stays — your exact buyer |
| Listing policy: whole-home only | Zero competition from shared rooms or private room listings |
| Longer average stays (4-7 nights) | Lower turnover cost, higher revenue per booking |
| Higher average booking value | VRBO guests book longer and pay more |
| Families + multi-gen travelers | The 5-bedroom/12-guest Lakeside Landing audience lives here |
| Expedia Group reach | Your VRBO listing also appears on Hotels.com, Travelocity, Expedia |

**For Lakeside Landing:** VRBO should add 12-18 additional booked nights in year one = **$15,000-$25,000 incremental revenue**.

**For Smooth Sailing:** VRBO should add 20-30 additional booked nights in year one = **$8,500-$12,750 incremental revenue**.

### Step 6: Headline (Max 70 Characters)

This is the listing's title in search results. Follow this formula:

**`[Unique Feature] + [Location] + [Emotional Hook]`**

Examples:
- ✓ "Private Lakefront Cabin w/ Dock on Seneca Lake | Sleeps 12"
- ✓ "Luxe Finger Lakes Retreat — Wine Country, Hot Tub, Firepit"
- ✗ "Nice house for rent in NY" (too generic)
- ✗ "Beautiful home with lots of amenities" (no specificity)

### Step 7: Description (The Conversion Engine)

VRBO descriptions have a different structure than Airbnb. Use these sections:

**Section 1: The Hook (First 2 Lines — Critical)**
Most guests only read the first 150 characters. Lead with the unique selling proposition.

**Section 2: The Space**
Describe the property in logical order: arrival → living areas → kitchen → bedrooms → bathrooms → outdoor.

**Section 3: The Location**
This is where VRBO differs from Airbnb. VRBO guests care deeply about proximity to activities.

**Section 4: What Makes This Special**
Include 3-5 specific amenities or features that differentiate you.

**Section 5: House Rules (Brief)**
Link to full rules but highlight key ones.

### Step 8: Pricing

VRBO pricing fields:

| Field | What to Set |
|---|---|
| Base nightly rate | Your "fair weather" rate |
| Weekend premium | 15-25% higher |
| Peak season rates | 30-60% higher than base |
| Off-season rates | 20-30% below base |
| Minimum stay | Season-dependent (2-5 nights) |
| Cleaning fee | $150-$350 depending on size |
| Damage deposit | $500-$2,000 |
| Extra guest fee | $25-$50 per person over base count |

**Pro tip:** VRBO displays the "total trip cost" by default, so inflating cleaning fees hurts conversion. Roll some cleaning cost into the nightly rate.

### Step 9: Calendar & Availability

- Set minimum night stay per season (use dynamic rules if your channel manager supports it)
- Set lead time (earliest booking window — usually 0 days, same-day booking allowed)
- Set advance booking window (how far out guests can book — usually 18-24 months)
- Block any personal-use dates

### Step 10: Cancellation Policy

VRBO offers 5 cancellation policy tiers:

| Policy | Full Refund | Notes |
|---|---|---|
| Relaxed | 14 days before | Guest-friendly, lowest conversion lift |
| Moderate | 30 days before | Balanced (recommended default) |
| Firm | 60 days before | Good for peak/holiday |
| Strict | 60 days before (partial 50% at 30) | Maximum host protection |
| No Refund | Never | Only for ultra-peak dates |

**Recommendation:**
- Lakeside Landing: **Firm** (peak rates justify longer cancellation window)
- Smooth Sailing: **Moderate** (more guest-friendly to maximize bookings)

### Step 11: House Rules

Write clear, complete rules. Keep it to 6-10 rules max.

**Standard rules:**
1. No smoking anywhere on property (including decks)
2. No parties or events (defined as 20+ non-registered guests)
3. No pets (or pet policy + fee)
4. Quiet hours: 10 PM - 8 AM
5. Maximum occupancy strictly enforced
6. Must be 25+ to book (optional but recommended for premium properties)
7. No shoes in house (if applicable)
8. Dispose of trash properly per posted instructions

## PART 4 — CHANNEL MANAGER SYNC (AVOIDING DOUBLE BOOKINGS)

**DO NOT GO LIVE** until you've synced VRBO to your PMS. Going live without sync = guaranteed double booking = 5-star review disaster.

### Option A: Hospitable (Recommended for 1-3 Units)

1. Log into Hospitable
2. Go to Integrations → VRBO
3. Click "Connect VRBO"
4. You'll be redirected to VRBO to authorize
5. Select your property from the list
6. Map your Airbnb calendar → VRBO
7. Sync takes 15-30 minutes initial, real-time thereafter

### Option B: Hostaway (Recommended for 4+ Units)

1. Log into Hostaway
2. Go to Listings → Add Channel → VRBO
3. Enter VRBO credentials
4. Map properties between platforms
5. Select sync direction (2-way recommended)
6. Confirm channel manager fees (usually included in plan)

### Option C: Direct VRBO-Airbnb Sync via iCal

Free but less reliable. Not recommended for premium properties where one double-booking costs $1,500+.

1. Export iCal URL from Airbnb
2. Import iCal to VRBO calendar
3. Export iCal from VRBO
4. Import to Airbnb
5. Sync frequency: every 2-4 hours (delay risk exists)

### Sync Verification

Before going live, do this test:

1. Block a random 3-day window on Airbnb
2. Wait 30 minutes
3. Check VRBO calendar — should show same block
4. Remove block on Airbnb
5. Wait 30 minutes
6. Verify VRBO calendar is open again

If sync works = go live. If not = troubleshoot before accepting bookings.

## PART 7 — POST-LAUNCH OPTIMIZATION (FIRST 30 DAYS)

Going live isn't the end. The first 30 days determine VRBO's algorithm ranking of your listing.

### Day 1-3: Immediate Actions

- [ ] Verify VRBO listing is LIVE (check from incognito browser)
- [ ] Test booking flow as a guest (dummy inquiry, cancel before committing)
- [ ] Verify calendar sync with Airbnb (block a date, check both)
- [ ] Set up instant book (boosts search ranking)
- [ ] Enable VRBO's "Premier Host" eligibility tracking

### Day 4-14: Active Optimization

- [ ] **Respond to every inquiry within 1 hour** (response rate = ranking)
- [ ] Send first booked guest welcome message (automated via PMS)
- [ ] Review your listing from guest perspective — fix any typos
- [ ] Upload 2-3 additional photos if gaps exist
- [ ] Check competitor listings for price/amenity alignment

### Day 15-30: Early Momentum

- [ ] **Request first review explicitly** — Day of checkout
  - Message: "We'd love your feedback! If everything was great, a 5-star review helps us continue hosting."
- [ ] Respond to your first review (even 5-star) publicly
- [ ] Adjust pricing based on booking pace
  - Lots of inquiries but no bookings = price too high
  - Bookings coming in fast = price could go up
- [ ] Join VRBO Academy for algorithm insights

### Day 31+: Ongoing Optimization

- [ ] Monitor search rank weekly (incognito search for your market)
- [ ] A/B test headline every 60 days
- [ ] Update seasonal photos (winter shots in winter, etc.)
- [ ] Refresh listing description quarterly
- [ ] Track conversion rate (views → inquiries → bookings)

## PART 9 — COMMON VRBO MISTAKES TO AVOID

| Mistake | Consequence | Fix |
|---|---|---|
| Using Airbnb description verbatim | Lower conversion, feels lazy | VRBO-specific structure with "The Space" / "The Location" / etc. |
| Skipping amenity checkboxes | Hidden from filtered searches | Check EVERY applicable amenity |
| Cleaning fee too high | Total price inflates, guests bounce | Roll some cleaning into nightly rate |
| Photo count under 20 | VRBO deprioritizes in search | Upload 20-40 high-res photos |
| No response to inquiries | Rank drops fast | Respond within 1 hour (set push notifications) |
| Calendar not synced | Double bookings = devastating reviews | Sync via Hospitable/Hostaway BEFORE going live |
| Over-selling occupancy | Bad reviews, damage issues | Be realistic — advertise 12 for an 8-comfortable layout = disaster |
| Generic headline | Low click-through from search | Use "[Unique Feature] + [Location] + [Hook]" formula |
| No minimum stay logic | Orphan nights kill calendar | Set season-based minimums (3-5 peak, 2 shoulder) |
