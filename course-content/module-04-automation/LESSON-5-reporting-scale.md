## VIDEO SCRIPT

### HOOK (0:00 - 0:20) [CANON 70D]
"If you want to scale past 5 units — or manage properties for other owners — you need reporting that runs itself and SOPs that let anyone execute your system. This lesson builds both."

### AUTOMATED MONTHLY REPORTS (0:20 - 3:30) [SCREEN RECORDING]

Walk through the Monthly Owner Report template:
- Revenue breakdown: gross revenue by platform, net revenue after expenses
- Occupancy rate vs target
- ADR and RevPAR vs last month and vs market
- Direct booking percentage and commission savings
- Review count and average score
- Maintenance issues and resolutions
- Upcoming month forecast (from PriceLabs projected revenue)

**[SCREEN RECORDING: Populating the report template with data from PMS and PriceLabs]**

For multi-property operators or property managers, this report goes to the property OWNER monthly. It's your deliverable that proves your value.

Set a calendar reminder: first of every month, pull data and generate report. Takes 15-20 minutes per property once the template is built.

### BUILDING SOPs (3:30 - 6:00) [CANON 70D + SLIDES]

"SOPs — Standard Operating Procedures — are the documents that let anyone run your systems without you.

**[SLIDE: 5 Core SOPs Every STR Needs]**

1. **New Booking SOP** — What happens when a booking comes in (mostly automated now, but document the exceptions)
2. **Guest Issue SOP** — Escalation tree: what to do for noise complaints, broken items, lockouts, emergencies
3. **Turnover SOP** — Cleaning standards, photo verification, supply restocking, quality check
4. **New Property Onboarding SOP** — Step-by-step for adding a new property to your system (PMS setup, channel connections, pricing, messaging, cleaning)
5. **Monthly Audit SOP** — The dashboard review, report generation, and optimization routine

Each SOP should be a simple Google Doc with:
- Trigger (what causes this process to start)
- Steps (numbered, specific, with screenshots)
- Tools used (which platform, which settings)
- Escalation (when to involve you)
- Done criteria (how to know it's complete)

Templates for all 5 are in your course resources."

### THE SCALING PLAYBOOK (6:00 - 8:00) [CANON 70D]

**[SLIDE: 'The Add-a-Property Playbook']**

"When you're ready for property #2, #3, or #10 — here's the exact sequence:

**Week 1: Setup**
- Add property to PMS
- Connect to all distribution channels (Airbnb, VRBO, Booking.com, Google)
- Set up PriceLabs with base rate, min/max, rules
- Configure all 8 guest message templates
- Set up Turno with local cleaning team

**Week 2: Optimization**
- Professional photos taken
- Listing copy written for each platform
- Direct booking page added to website
- StayFi configured for new property
- Email sequences tagged for new property

**Week 3: Launch**
- Listings go live on all platforms
- First 2 blog posts published for new property
- Social content announcing new property
- Google Business Profile created

This playbook is the same every time. Property #10 takes the same 3 weeks as property #2. That's the power of systems."

### CLOSE (8:00 - 9:00) [CANON 70D]
