# MODULE 3: DYNAMIC PRICING & REVENUE — PRODUCTION GUIDE

## Overview
- **4 Lessons** | ~40-50 minutes total video
- **5 Templates** (pricing matrices, discount calculators, upsell menu, fee worksheet)
- **Goal:** Student has dynamic pricing live on all platforms, fee strategy optimized, upsells active

## LESSON INVENTORY

| # | Lesson | Length | Primary Camera |
|---|--------|--------|---------------|
| 1 | Pricing Psychology | 8-10 min | Canon 70D (conceptual) |
| 2 | Market Data & Competitive Pricing | 10-12 min | OBSBOT (AirDNA screen recording) |
| 3 | Dynamic Pricing Setup (PriceLabs) | 12-15 min | OBSBOT (full PriceLabs walkthrough) |
| 4 | Revenue Maximization | 10-12 min | Mixed (strategy + PMS/PriceLabs config) |

## RECORDING PLAN

### Canon 70D Session (1-1.5 hours)
- Lesson 1: Full lesson (mostly on camera)
- Lesson 2: Hook + analysis framework + close
- Lesson 3: Hook + close (30 seconds each)
- Lesson 4: Strategy sections + module wrap-up

### OBSBOT Screen Recording Session (2-2.5 hours)
- Lesson 2: AirDNA deep dive — seasonal data, day-of-week, events, competitor pricing
- Lesson 3: FULL PriceLabs setup — 13 steps from account creation to live pricing
- Lesson 4: PriceLabs discount ladder config + PMS fee settings

### Editing (3-4 hours)
Module 3 is tighter than Module 2. Less screen recording, more conceptual content.

## ESTIMATED PRODUCTION TIME

| Task | Time |
|------|------|
| Script review | 1 hour |
| Canon recording | 1-1.5 hours |
| OBSBOT screen recording | 2-2.5 hours |
| Template creation | 2 hours |
| Slide creation | 1.5 hours |
| Editing & assembly | 3-4 hours |
| Review | 1 hour |
| **Total** | **12-16 hours** |

**Module 3 is a single weekend project.** Fastest module to produce because it's focused and tool-heavy.
