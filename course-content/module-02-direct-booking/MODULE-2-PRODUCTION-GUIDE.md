# MODULE 2: DIRECT BOOKING ENGINE — PRODUCTION GUIDE

## Overview
- **6 Lessons** | ~65-80 minutes total video
- **20+ Templates** (emails, blog posts, checklists, calculators, ad copy)
- **Goal:** Student has a live direct booking website, automated funnels, 6 traffic channels, and measurement dashboard

---

## RECORDING PLAN

### Session 1: Canon 70D — Talking Head (2-2.5 hours)
- Lesson 1: Full lesson (strategy-heavy, mostly on camera)
- Lesson 2: Intro + close
- Lesson 3: Hook + strategy sections
- Lesson 4: Strategy overview + close
- Lesson 5: Strategy + channel overview + referral section + close
- Lesson 6: Monthly audit explanation + A/B testing + module wrap-up

### Session 2: OBSBOT — Screen Recordings (3-4 hours)
- Lesson 2: FULL SITE BUILD (Lodgify — 12+ min of screen recording)
- Lesson 3: StayFi setup + pre-arrival form + survey + email platform integration
- Lesson 4: Email sequence builder (ConvertKit/Mailchimp) — 5 sequences
- Lesson 5: Google Business optimization + blog setup + Google Ads campaign
- Lesson 6: GA4 setup + dashboard walkthrough

### Session 3: Editing (5-7 hours)
Module 2 has the most screen recording of any module. Budget extra editing time for:
- Zoom effects on screen recordings (highlight clicks)
- Speed up repetitive actions (2x speed with voiceover)
- Add step number overlays on screen recordings
- Add branded lower thirds identifying which tool is on screen
